# Primeiros passos no Claude Code

1. Descompacte a pasta `louvor-pibvg` em um lugar fixo do computador (ex.: Documentos).
2. Abra o Claude Code nessa pasta (no app: abrir pasta/projeto; no terminal: `cd louvor-pibvg` e `claude`).
3. O Claude Code lê o `CLAUDE.md` sozinho. Para conferir, peça: "Resuma o projeto e as pendências".
4. Para publicar alterações ele usa `git push`. Na primeira vez o Git vai pedir login no GitHub:
   entre com a conta **louvorpibvg** (você mesmo faz o login no navegador ou no GitHub Desktop).
5. Opcional: conectar o Supabase ao Claude Code (MCP do Supabase) para ele consultar e alterar o banco.
   O login é feito por você; nunca cole senhas ou chaves secretas no chat.

A pasta `_privado/` fica só no seu computador (não é enviada ao GitHub). Faça backup dela.
